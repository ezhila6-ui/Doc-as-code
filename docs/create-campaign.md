# Create a Campaign

Campaigns allow administrators to send security awareness training to users.

## Create a campaign

1. Sign in to SecureAware.
2. Select **Campaigns**.
3. Select **Create campaign**.
4. Enter a campaign name.
5. Select the required training content.
6. Select the users who will receive the campaign.
7. Configure the campaign schedule.
8. Select **Create**.

The campaign appears on the Campaigns page.

## Campaign status

A campaign can have one of the following statuses:

| Status | Description |
|---|---|
| Draft | The campaign has not been launched. |
| Scheduled | The campaign is scheduled for delivery. |
| Active | The campaign is currently running. |
| Completed | The campaign has finished. |
